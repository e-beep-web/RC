¿Qué sé ya?

2.º ESO · cuestionario inicial, sin nota

Antes de empezar

Esto no es un examen y no cuenta para nada. Sirve para que sepamos de dónde partimos y para ajustar el ritmo de las primeras semanas. Si no sabes algo, responde lo que te parezca o déjalo en blanco: es información igual de útil.

1. Un algoritmo es…

Primero se piensa el algoritmo y después se escribe el programa. Lo verás en la UD1.

2. En un lenguaje de bloques, un bloque que dice «repetir 4 veces» sirve para…

Es un bucle. Con él ahorras escribir el mismo bloque muchas veces. UD1.

3. ¿Cuál de estas máquinas es un robot?

Un robot percibe, decide y actúa. Si le falta una de las tres, no lo es. UD3.

4. Un sensor sirve para…

Sensor mide, controlador decide, actuador actúa. UD3 y UD4.

5. ¿Cuál de estas contraseñas es más difícil de adivinar?

Lo que protege es la longitud y que no sea previsible, no meter símbolos raros. UD9.

6. Una aplicación de linterna te pide acceso a tus contactos. ¿Qué significa?

La pregunta clave siempre es: ¿necesita ese permiso para lo que promete? UD5.

7. El HTML de una página web sirve para…

HTML dice qué hay, CSS cómo se ve y JavaScript qué hace. UD6.

8. ¿Has programado alguna vez con bloques (Scratch, mBlock u otro parecido)?

9. ¿Has montado o programado un robot alguna vez?

10. ¿Has creado alguna página web o has tocado código HTML?
